# Requisitos

## Requisitos funcionales
| Código | Descripción |
|---|---|
| RF01 | El sistema muestra la temperatura y la humedad del aire |
| RF02 | El sistema muestra la humedad del suelo |
| RF03 | El sistema muestra el nivel de luz |
| RF04 | El usuario puede encender y apagar la bomba de riego |
| RF05 | El usuario puede encender y apagar el ventilador y la luz |
| RF06 | El sistema riega automáticamente si la humedad del suelo es baja |

## Requisitos no funcionales
| Código | Descripción |
|---|---|
| RNF01 | La página se adapta a la pantalla del celular |
| RNF02 | Los datos se actualizan cada pocos segundos |
| RNF03 | La electrónica está protegida de la humedad |
