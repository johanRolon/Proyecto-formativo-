## Objetivo general
Construir un invernadero miniatura de 30 x 30 cm con monitoreo y control
remoto mediante una página web y una aplicación móvil.

## Objetivos específicos
- Medir temperatura, humedad del aire, humedad del suelo y luz.
- Controlar riego, ventilación e iluminación.
- Mostrar los datos en una página web.
- Manejar la página como aplicación con App Inventor.
- (Opcional) Guardar el historial en una base de datos SQL.
