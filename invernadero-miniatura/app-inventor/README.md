# App Inventor

Aquí va el archivo `.aia` exportado desde App Inventor.

## Cómo está armada la app
- Una pantalla con un componente **WebViewer**.
- Al iniciar, el WebViewer abre la URL de la página del invernadero.

## Para exportar el proyecto
En App Inventor: Proyectos > Exportar proyecto seleccionado (.aia).
